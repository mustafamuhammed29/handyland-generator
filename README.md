## 🔒 Strict eBay Policy Compliance (Zero-JS Guarantee)

eBay strictly prohibits active scripting and external resource execution in listing descriptions. The output generated by this tool is guaranteed to pass all eBay security verifications:

- **Zero JavaScript:** No `<script>` tags, no inline JavaScript event handlers (`onclick`, `onload`, etc.).
- **No External Stylesheets:** No external `<link rel="stylesheet">` tags; all CSS is completely embedded inside a scoped container.
- **Native HTML5 Interactive Elements:** Uses native `<details>` and `<summary>` elements for interactive FAQ accordions without any scripting.
- **Cross-Device Responsive:** Fully responsive layout with custom `@media` queries that render cleanly on desktop browsers, mobile web, and the official eBay iOS/Android apps.
- **Lightweight Unicode Icons:** Utilizes high-compatibility Unicode symbols and emojis instead of heavy external icon fonts like FontAwesome.

## 🚀 Getting Started

### Local Development

This project runs natively using modern standard ES Modules. No complex build tools or heavy dependencies are required.

#### Option 1: One-Click Launch (Windows)
Double-click [`start.bat`](start.bat) to start the local server and automatically open your default browser at `http://localhost:3000`.

#### Option 2: Using Node.js (npm)
```bash
npm start
# or
npm run dev
```

#### Option 3: Using Python
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your web browser.

## 🛠️ How to Generate & Publish an eBay Listing

1. Open the [Generator Dashboard](https://mustafamuhammed29.github.io/handyland-generator/).
2. Select the **Brand** (e.g., Apple), enter the **Model** (e.g., iPhone 13 Pro), and choose the **Repair Type** (e.g., Display / Bildschirm).
3. Set your service price and configure optional upgrades (such as tempered glass).
4. Click **"📋 Code Kopieren"** to copy the generated pure HTML template.
5. In your **eBay Seller Hub (Verkäufer-Cockpit Pro)**:
   - Paste the SEO title into the Item Title field.
   - Switch the Item Description editor to **"HTML Mode" (HTML-Code)** and paste the copied template code.
   - Save and publish your listing!
